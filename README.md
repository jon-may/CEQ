# CEQ
_Craving experience questionnaire_

This questionnaire measures the intensity, imagery and intrusiveness of thoughts what occur when people crave something. There is a version that measures the strength of each aspect, and another than measure the frequency that each aspect occurs. Both forms can be modified to address cravings that have happened over a defined time period (e.g., the last day or week), and the strength version can address either a craving happening right now, or the strongest craving that happened over a previous time period.

Although intended as a 10 item scale, it is distributed as an 11 item scale, with two versions of one item (mouth/throat and body feel) as the former works best with alcohol, and the latter with activities. Please delete one of these items, either at presentation or in the analysis phase.

It has also been adapted to focus on cravings for specific targets (e.g., chocolate, alcohol) and for Motivation Thoughts.

This archive includes the data reported in the original paper along with an R script to read the data and reproduce some of the results. You can find these in the Data folder.

The questionnaire is freely available for you to use in your own research. Several teams have published translations, and you can find these in the Questionnaires folder. These are also free for you to use, provided that you cite and attribute appropriately. If you translate it into another language, please do send us a copy to add to this archive.
